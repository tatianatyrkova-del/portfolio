# Портфолио Татьяны Тырковой

Руководитель спецпроектов и партнерского маркетинга.

Статический сайт: `index.html` + папка `assets` (фото и видео) + `crm-demo.html` (демо дашборда Project Room).

## Как опубликовать на GitHub Pages

1. На github.com создайте новый репозиторий, например `portfolio` (Public).
2. Нажмите **Add file → Upload files** и перетащите **всё содержимое** этой папки: `index.html`, `crm-demo.html`, `README.md`, `.nojekyll` и папку `assets` целиком. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветка **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/portfolio/`.

Если файл `.nojekyll` не виден при загрузке (скрытый файл), можно его не загружать — сайт будет работать и без него.

## Как обновлять

Замените нужный файл через **Add file → Upload files** (с тем же именем) и сделайте Commit — сайт обновится сам через 1–2 минуты.
